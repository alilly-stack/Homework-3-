# Homework 3 - Responsive Layout

## Project
Town Square is a community/neighborhood website. It intentionally uses no astronomy or Cosmos theme.

## Files
- `index.html` — semantic HTML page
- `style.css` — external stylesheet linked in the HTML head

## Requirements demonstrated
- External stylesheet: `<link rel="stylesheet" href="style.css">`
- Type selectors: `body`, `h2`, `h3`, `p`, `figure`, `img`, `figcaption`, `a`
- Class selectors: `.site-header`, `.tagline`, `.nav-list`, `.page-content`, `.content-card`, `.discovery-card`, `.fact-list`, `.site-footer`
- ID selector: `#main-title`
- Box model: margins, padding, borders, and `box-sizing`
- Coordinated community color palette: green, cream, muted orange, and blue accents
- CSS Grid and Flexbox
- Responsive breakpoints: mobile (600px and below, tested at 320px), tablet (up to 900px, including 768px), and desktop (full layout at 1200px)
- Layout widths and wrapping prevent horizontal overflow.

## Test
Open `index.html` in a browser and use developer tools to test viewport widths of 320px, 768px, and 1200px.

## GitHub submission
1. Create or open your GitHub repository.
2. Upload `index.html` and `style.css` into the same folder (the repository root is fine).
3. Commit the files.
4. Submit your own repository URL to your instructor.
5. If a live website is required, enable GitHub Pages in repository Settings > Pages.
